# AeroVision: concept landing page

Static landing page for AeroVision, a venture concept developed as part of the Aerospace MBA at EOI. It explores software for hands-free, aviation-specific maintenance and inspection workflows. No product exists yet, and the benefits described are hypotheses to be tested in pilots.

Live site: https://aerovision-ar.com

## Deployment

Served by GitHub Pages from the root of `main`. Keep the `CNAME` file: it holds the custom domain.
